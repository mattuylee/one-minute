# 稍等 / One Minute

纯 Kotlin 安卓应用。给选定应用加一段打开前的等待，默认 60 秒。

## 使用

1. 安装 APK，打开「稍等」。
2. 选择需要等待的应用，按需调整统一时长（1～600 秒）。
3. 在应用的「使用说明」中前往系统无障碍设置，开启「稍等」。
4. 打开选定应用，等倒计时结束后点击「继续打开」。随时可以选择「先不打开了」返回桌面。

侧载 APK 后，如果 Android 提示「受限设置」，在系统应用信息页按系统提示允许受限设置，再开启无障碍服务。部分系统还需要手动允许后台运行。首页显示实际服务连接状态。

## 第一版的规则

- 同一次前台会话只等待一次，应用内跳转和键盘事件不重新计时。
- 返回桌面、切换到另一个应用，再回来时重新等待。
- 锁屏会结束会话；解锁后重新等待。服务被重启也不保留放行记录。
- 打开系统遮挡窗口会取消尚未完成的等待；已经放行的会话不会仅因系统窗口重置。
- 倒计时到零后仍需点击继续，不自动放行。
- 所选应用共用一个等待时长；修改时长会影响下一次等待。
- 桌面、系统设置、权限管理、拨号和本应用不能加入拦截名单。
- 应用内提供等待页预览，不需要先授予权限。

这是一款自我约束工具。无障碍服务在目标应用进入前台后覆盖等待页，无法保证应用未启动、未短暂显示画面或未播放音频。关闭服务、卸载、画中画等不在第一版的强制防绕过保证范围内。

## 实现

- Kotlin + Jetpack Compose：应用列表与设置。
- AccessibilityService + TYPE_ACCESSIBILITY_OVERLAY：识别应用窗口、显示原生等待页。
- DataStore：只保存包名集合和统一等待秒数。
- 纯 Kotlin 状态机：计时使用 elapsedRealtime，重复事件不重置，过期回调不能放行新会话。
- 无网络权限、无广告 SDK、无统计、无后台服务器。无障碍仅读取窗口类型及根节点的包名，不遍历页面、不读取文字、不执行手势、不截图。
- 不申请使用情况访问、普通悬浮窗、设备管理员或通知权限；不运行轮询应用使用记录的前台服务。

界面参考 ScreenZen 的圆角卡片、留白与紫色强调色，所有代码和资源独立编写，未复制 ScreenZen 或 Mindful 的源码、商标或素材。

## 构建与测试

使用 JDK 17、Android SDK 36、Build Tools 35.0.0。最低 Android 12（API 31），目标 Android 16（API 36）。

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

本机在 `local.properties` 中填写 `sdk.dir`，该文件不提交。调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。发布版需要配置自己的签名密钥；密钥不应放进仓库。

自动化测试覆盖会话状态与原生等待页按钮行为。Robolectric 使用 API 35 绘制实际等待页，输出在 `app/build/reports/ui/`；这不能替代 Android 16 真机对无障碍服务、手势和厂商后台管理的验证。

## 真机验收

安装后依次检查：桌面打开、通知打开、最近任务切回、应用内跳转、键盘、锁屏解锁、系统通知栏、两个受限应用互相切换、横竖屏、深色模式、大字体、重启与撤销无障碍权限。重点观察是否重复等待、是否出现提前放行、是否阻挡系统操作。

初版不发布应用商店，暂不支持应用分身、工作资料跨用户识别和强制防卸载。
